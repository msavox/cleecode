# Caso 6 — un file che non si esegue

Markdown non ha (e non deve avere) un comando di esecuzione: il pulsante dice
"nessun comando" **prima** di premere ▶, invece di lasciartelo scoprire
dall'errore in fondo allo schermo.

Se poi lo vuoi, il menu te lo lascia impostare lo stesso — per esempio
`pandoc {file} -o {dir}/{stem}.pdf`.
