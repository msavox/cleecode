CleeCode

il tuo IDE nel terminale

Il tuo agente. Il tuo abbonamento.
Dentro il tuo editor.

claude · codex · opencode · gemini — editano i tuoi buffer in diretta. Niente chiavi API. Niente intermediari.

Abbonamento o chiave API: vanno bene entrambi. L'agente è la vera CLI e si autentica da solo. CleeCode non vede mai una credenziale.

Installa GitHub

macOS, Linux e Windows · MIT · note di release

L'agente in casa

Un tasto. Zero configurazione.

Ctrl+Shift+A e l'agente compare accanto al tuo lavoro: la CLI vera, in un terminale vero. Vede dove sei col cursore. Edita i buffer sotto i tuoi occhi. E prima di scrivere, chiede il permesso.

Sette strumenti MCP, le regole del consenso, la riga di configurazione per gli agenti fuori dal cassetto: tutto nel tour su GitHub.

Immagini, PDF, Markdown

Un terminale che le immagini le mostra davvero.

Pixel veri. Anche via ssh.

Rende al meglio in Ghostty, kitty, WezTerm o iTerm2; altrove degrada con grazia, senza perdere nulla. I dettagli nel tour.

Markdown & LaTeX

I tuoi documenti, renderizzati.

Il Markdown diventa un documento accanto al suo sorgente: scrivi da una parte, si aggiorna dall'altra. Il LaTeX torna in pagina a ogni Run.

Octave & Python

Il tuo interprete, col pannello che nessun terminale ha.

Ogni variabile, in tempo reale. I grafici diventano schede. E al tuo prompt scrivi solo tu.

Celle, breakpoint, variabili del frame: la guida completa.

Il lavoro di ogni giorno

Rename. References. Format. Code actions.

La potenza del language server, con la disciplina di git: ogni riscrittura prima ti mostra il diff, poi si applica in un solo undo. E Ctrl+Shift+D è un pannello git completo — la storia disegnata a grafo, gli hook che girano, i commit firmati.

200 linguaggi, replace su tutto il progetto, selezione a colonna, folding: la lista completa.

A prova di crash

Non ti si chiude addosso.

Ammazza l'editor con kill -9: al prossimo avvio il testo non salvato torna. Provato sul binario vero, ucciso per davvero.

Dall'altro capo dell'ssh

Niente da installare, di là.

Un binario. Il mouse funziona. L'output del compilatore si clicca. Nove temi, inglese e italiano.

Installa

Tre righe su macOS e Linux.

brew tap msavox/clee
brew trust msavox/clee
brew install clee

Un Homebrew più vecchio non ha brew trust e non ne ha bisogno — saltalo.

Due su Windows.

scoop bucket add clee https://github.com/msavox/scoop-clee
scoop install clee

Binari precompilati

Allegati a ogni release.

  • macOS arm64

    Apple silicon. La piattaforma di casa.

  • macOS x86_64

    I Mac Intel.

  • Linux x86_64

    Servono glibc e libxcb.

  • Linux arm64

    Server, e Raspberry Pi OS a 64 bit.

  • Windows x86_64

    Sperimentale — le segnalazioni sono benvenute.

Da sorgente

cargo install --locked --git https://github.com/msavox/cleecode

Rust 1.85+. Poi clee --install-font per le icone; su macOS, clee --install-app per il Dock.

Tutto quello che vedi qui è costruito e provato — nessuna promessa. Una parte vive su master oltre l'ultimo tag: le note di release dicono cosa trovi dove.
